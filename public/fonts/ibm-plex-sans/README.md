# IBM Plex Sans

Arquivos WOFF2 oficiais, completos e sem alterações, usados pelo laboratório de design nos pesos 300, 400, 500, 600 e 700.

Origem: [IBM/plex](https://github.com/IBM/plex/tree/763c36ef9117782905ae010056dfbe8fd2653a25/packages/plex-sans/fonts/complete/woff2), revisão `763c36ef9117782905ae010056dfbe8fd2653a25`.

A licença SIL Open Font License 1.1 acompanha os arquivos em `license.txt`.

O carregamento usa `next/font/local`, mantém `--font-plex-sans` e `display: swap` e evita o erro do resolvedor de arquivos Google do Turbopack durante o build de produção.
